安卓覆盖手动恰好一帧、500 ms 自动选帧、停止/立即停止后保持结果、K 和 JSON、无效深度、缺帧超时、权限、枚举暂缺/抛错、授权期间枚举变化、断线重连；USB 检查覆盖 BUSY 分支、快速回调、部分提交失败、传输队列耗尽、延迟取消和释放失败重试。

旧入口默认连续处理、新入口默认暂停都已检查。旧板生成器的源指纹改为 LF 规范化，避免 Windows CRLF 造成只改元数据的假失败；没有重写硬件编码期望值。

自动回归使用模拟 USB。它不能代替手机内核的 claim/等时传输、供电及长期稳定性验证。当前 APK 由整理后的源码重新构建，SHA-256 见 [安装包目录](../../deliverables/vision/android/README.md)；构建路径/源码整理导致它不与早先现场 1.2 逐字节相同。

## 整理前的真实硬件证据

Windows 使用既有 libusbK 驱动和真实 CS30，6 轮开流/停流收到 **489 帧**，包错误和不完整帧均为 0。每轮手动单帧、自动 3.2 秒内 7 帧（含立即首帧）、停止冻结和重开通过。未改驱动，未调整相机摆放；当前样本不满足地面拟合条件，因此未评估检障准确率。紧凑记录：[pc-connection.json](validation/pc-connection.json)。

手机方面，用户确认给扩展坞 PD 口接充电宝后可用；未登记手机型号/鸿蒙小版本、长时运行和端侧实测资源。本轮整理后的共享核心/新构建尚未重新完成现场长时验收。

历史自动测试记录：[android-1.2.json](validation/android-1.2.json)。它与同目录历史 build JSON 的哈希对应早先验证包，不冒充本次重新构建的产物。

## 历史模型比较

2026-11-04，固定 10 个 NYU 场景，16 组主组合和 6 组消融，共 220 个场景配置，没有训练。指标是可见物体区域并集 IoU，排除地面/墙/天花板和未标注像素，**不是避障准确率或 COCO mAP**。

| YOLO | 原生分割 | +MobileSAM | +SAM-B | +SAM2.1 Tiny |
|---|---:|---:|---:|---:|
| v8n-seg | 25.31% | 24.44% | 24.05% | 25.05% |
| v8s-seg | 30.86% | 29.32% | 27.13% | 28.22% |
| 11n-seg | 25.59% | 24.47% | 22.33% | 23.82% |
| 11s-seg | 26.32% | 25.45% | 23.03% | 24.14% |

这批数据中，增加 SAM 没有改善整体区域指标；正常深度过滤下，RGB 障碍支持格都已包含在几何占据格中。故当前交付优先完成深度主线，YOLO 作为后续实例关联，SAM 不列入默认 pipeline。

历史 CPU 隔离模型调用：v8n 约 0.30 s、v8s 约 0.68 s、MobileSAM 约 2.65 s、SAM-B 约 24.39 s、SAM2.1 Tiny 约 6.93 s。它们不是完整 pipeline 耗时或手机性能承诺。大模型、数据集及全部逐图产物未放入本交付。
