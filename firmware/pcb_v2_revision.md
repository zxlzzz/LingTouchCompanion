## 1. V1 问题清单

### 1.1 已确认成因

| P7 | 模块焊死不可换 | 6.5mm 水平 / 11mm 垂直中心距、12 脚通孔，拆一个必伤邻位与焊盘 | 坐标文件确认：U31–U45，X 间距 6.5mm、Y 间距 11mm |

### 1.2 高度怀疑但未证实

| # | 问题 | 依据 | 验证路径 |
|---|---|---|---|
| S1 | 自动布线导致地平面破碎、电源走线过细、去耦被放远 | V1 用嘉立创自动布线；脉冲负载下地弹与压降会放大 P1/P2 | V2 直接手工布电源和地 |
| S2 | 大量死点源于**焊接热损伤**而非来料次品 | SMA 相变温度远低于焊接 250–350°C；热可致记忆形状丧失、锁定机构软化变形卡死；能解释"同模块部分点坏部分点好" | 空间分布分析不可行（靠前编号为旧拆机件、靠后为新件，样本不同质）；替代切分 = 新件 vs 旧件失效率对比；根本验证依赖无界的焊接工艺参数 |
| S3 | VCCS/VCC 峰值电流预算不明 | 无电流采样手段，step 上限只能估算 | **无示波器，板上测不到**；只能向无界索取单点峰值电流规格 |

### 1.3 已排除、不再讨论

- 供电轨压降梯度 / 批次电流下垂
- bit 序映射错误
- VCCS 过压（**2.0V 是设计值，ULN 达林顿压降约 0.9V，SMA 实际得 1.1–1.2V，正确**）
- 线圈欠驱动（3.6V 无变化）
- 时序不足（phaseA/B 扫到 300/200、phaseC 到 500 无效）
- SMA 未解锁（每模块均验证解锁正常）
- 焊点问题（线圈电阻一致、SMA 电阻一致）

**结论：死点为模块内部锁定机构卡死/变形，外部不可恢复。** V2 不做任何软件补偿设计，该问题随模块连接方式一并解决。

## 2. V2 电源架构 [必改]

### 2.1 前提修正

**电池是 12V DC 输出（带 DC 公母头，可充可放）**，不是单节锂电。这推翻了 v1/v2 报告中"取消 5V 中间级"的写法——那条结论建立在"电池 3.7–4.2V、5V 需升压"的错误前提上。

12V 母线下，**全部轨均为降压，没有任何升压级**，P1 的成因（LDO 压差 3V 发热）与 5V 轨本身无关。

### 2.2 拓扑

```
12V 电池（DC 公母头，自带充放电）
  │
  └─ [SW2 自锁开关] ──→ [现成 DC-DC 模组 U51，VIN 12V]
                          │
                          ├─→ 5V / 3A ─┬─→ ESP32 DevKit 5V 脚（板载 LDO 兜底）
                          │            ├─→ [同步 Buck U52] VCCS 2.0V  ← SMA，脉冲
                          │            └─→ [同步 Buck U53] VCC  3.2V  ← 线圈，脉冲
                          │
                          └─ 3V3 / 3A ──→ VCC_LOGIC  ← 15× 595 逻辑
```

**为什么 ESP32 走 5V 脚而不是 3V3 脚：** 3V3 脚旁路板载 LDO 直连芯片，会与 USB 供电对顶（§6 要求装配后 USB 可插），且失去对 BLE 发射 300–500mA 台阶的缓冲。5V 脚保留板载 LDO，这两个问题都不存在。

**为什么两颗 Buck 输入取 5V 而不是 12V：** 压差小、电感小、效率高；U51 的 5V/3A 有余量（ESP32 峰值约 0.5A + 两轨折算输入约 1.2A ≈ 1.7A）。
> 需确认 U51 标称 3A 是持续还是峰值。若为峰值，改从 12V 直接给两颗 Buck 供电。

### 2.3 逐轨要求

| 轨 | 电压 | 来源 | 裕量 | 储能 |
|---|---|---|---|---|
| VCCS | 2.0V | **同步 Buck（禁用 AMS1117）** | 峰值按 step=12 约 1.2A → **选 3A 级** | 470–1000µF 低 ESR + 每模块就近 100nF（C16–C30 保留） |
| VCC | 3.2V | 同步 Buck | 3A 起（待线圈电阻实测确认） | 470–1000µF + **新增 15× 100nF 就近去耦（V1 为零，见 P11）** |
| VCC_LOGIC | 3.3V | U51 的 3V3 输出，**独立** | 几十 mA | 每颗 595 就近 100nF（C1–C15 保留，改挂新源） |
| ESP32 | 5V→板载3.3V | U51 的 5V 输出 | — | 模组自带 + 100µF |

**硬性约束：**
1. `VCC_LOGIC` **绝不再从 `VCC` 经磁珠分出**，FB1 删除。
2. 主电源路径**不串磁珠**。
3. 四轨回流在**电池负极单点汇合**，不在板中间共地路径。
4. VCCS 主干走线 ≥ 2mm 或直接铺铜。
5. **现成模组一律焊死**，通孔焊盘直插，禁止排针插接（P4 的直接成因）。

### 2.4 关于"自己画 vs 用成品"

- **U51（12V→5V/3V3）用手头现成模组**，板上画一排 2.54 通孔焊盘让它引脚直插焊死。不飞线。前提是先量准引脚间距与排布，画进封装库。
- **U52/U53（VCCS/VCC）自己画**，但**照数据手册参考设计原样抄**，元件值不做任何"优化"；立创商城对常用型号有验证过的参考电路。风险来自芯片厂而非本项目。

**不做"面积预留"。** 不确定性用器件裕量吸收，不用板上空地吸收。

### 2.5 备忘：电容电感的作用

- **电容 = 本地储能**。线圈瞬间抽 1A，稳压器环路响应需几 µs–几十 µs，这段时间由电容供给。容量够大、位置够近，轨就不塌。
- **电感 = 开关电源必需件**，非可选，值照手册取。
- **堆料不是线性变好**：电容超量后收益趋零，还会带来上电浪涌与环路不稳。稳定来自结构正确（轨分离、地平面完整、去耦就近、稳压器选型对）。

## 3. 可测性 [必改，已按"无示波器"砍定]

前提变更：**本项目无示波器，且不为此采购。** 所有依赖动态波形的检查项（电流采样电阻位、分散裸铜探针盘、ULN 输出测试点）**全部删除**——加了也读不出来。

保留四条，全部是万用表或固件能直接用的：

| # | 实物 | 数量 | 干什么 |
|---|---|---|---|
| T1 | U15.9 (QH′) → ESP32 空 GPIO | **1 根走线** | 上电发已知数据再读回，验证 15 颗 595 全焊好、链未断、位序正确 |
| T2 | 板边 2.54 排针 J_TEST | **6P × 1** | VCCS / VCC / VCC_LOGIC / 5V / GND / GND，万用表夹静态电压，也可挂鳄鱼夹 |
| T3 | 电池分压 R6/R7 → ADC | **2× 0603** | 固件持续记录电池电压，串口有时间轴可对 |
| T4 | NTC 热敏 RT1 + R8 → ADC | **2 件** | 贴 ULN 群中央。访谈把"偶尔触发"变成"持续刷新"，ULN 与稳压器从瞬时发热变连续发热，热限制目前空白（§5.4-3 仍挂着问无界）。**这是唯一一个没有仪器也能自己拿到新数据的检查项**，跑一次连续刷新就能测出来 |

> 目标：下一版若仍不稳，**半小时内定位**，而不是排查数周。

**模块焊前预检**不在主板上，见 §5.5。

## 4. 布线 [必改]

| 项 | 要求 |
|---|---|
| 布线方式 | **电源与地手工布**。信号可自动布线，但布完人工复查 SPI 时钟、SRCLR#、OE# |
| 层叠 | L1 信号 / **L2 完整 GND 平面（不得切割）** / L3 电源平面（VCC / VCCS / VCC_LOGIC 分区） / L4 信号 |
| 电源线宽 | VCCS、VCC 主干 ≥ 2mm 或铺铜区 |
| 去耦 | 电容紧贴芯片电源脚，到地平面过孔尽可能短 |
| 分区 | **驱动芯片跟着阵列走、电源集中在另一端，这个格局是对的，不动。** 不做任何"左右均衡分布"式的调整——那只会拉长信号线 |
| 方向 | **按最终装配方向布局，取消物理 180° 旋转**。SW1 直接画在拇指位置，不再靠脑内换算 |

**取消 180° 旋转的收益：** 消掉 `MODULE_ROT180` 三处同步、消掉 `posToChain` 倒序、消掉两次 bit remap 中至少一次，并消掉"图纸上是左、手上是右"的元件位置换算。纯布局问题，零成本。

## 5. 模块连接方式 [待定 — 唯一悬空项]

**V2 唯一无法在这边定稿的部分，其余章节均可先行画板。**

### 5.1 已知事实
- 模块 12 脚双排直插，间距实测约 **1.25mm**（需重新精确复测）
- **引脚不完全对齐**，部分引脚间距有偏差
- **针本身较软**
- 杜邦转 1.25 端子勉强可插，接触效果差

### 5.2 判断
引脚软 + 位置有偏差 → 该模块很可能本就是设计为焊接使用的。若设计为插接，引脚会做硬、对齐精度高、带防呆。

### 5.3 候选方案

| 方案 | 优点 | 风险 | 状态 |
|---|---|---|---|
| A. 1.25mm 排母 | 标准件、便宜、可换 | 簧片小、容差有限，软针可能插弯 | 值得用报废模块试插，成本几元 |
| B. Pogo pin 压接 | 容忍位置偏差、不插弯软针、完全可插拔 | 需机械压紧结构，窄手柄内难做 | 手柄内否决；**但工装上完全可行，见 §5.5** |
| C. 焊接 + 焊前测试工装 | 现实可行；解决 80% 痛点（怕的不是坏了不能换，是焊完才发现坏） | 单模块仍不可换 | **保底方案** |
| D. 主板/子板分体 | 隔离贵且难焊的部分，报废范围可控 | 切口必须在 **SPI 层**（子板含 15 模块 + 15×595 + 15×ULN，接口收敛到约 9–10 根）；切在模块引脚层需 105 根信号，不可行 | 视 A/B/C 结果决定 |

> 方案 D 的子板**不是"可换模块"，是"可换显示总成"**。若采用，连接器的 VCCS 与 GND 必须各占 3–4 针并联。
> 每模块做独立小板菊花链**不推荐**：15 块小板各自的 Z 向误差会破坏阵列共面度，指腹读取对平面度极敏感。

### 5.4 待现场确认（无界）
1. 模块物理装配方式：定位、共面度、面板开孔尺寸、模块与面板间隙
2. **焊接工艺参数：温度曲线、单点停留时间上限、散热措施** ← 直接决定 S2 与 V2 是否必须弃焊
3. 官方驱动时序：SMA 开启窗口、线圈保持时长、最小间隔、**连续工作热限制**
4. **电流规格：单点峰值、平均、同时可驱动上限** ← 电源预算的地基，且无示波器时只能靠此
5. 是否存在带连接器/座子的模块版本
6. 是否使用分组复用降低驱动芯片数
7. 锁定机构卡死的成因与预防、进料检测方式
8. 模块高度一致性公差

> 完整原理图大概率要不到，也不需要。改问"应用支持 / 参考设计如何处理 XX 问题"，成功率高得多。带上失效模块实物与精确失效档案前往。

### 5.5 焊前预检工装（排在无界调研之后）

**形态：** 独立小板，不上手杖、不进壳，台面夹具。
- 12 个 pogo pin 按模块引脚阵列排布，上方翻盖压板（合页 + 蝶形螺丝）
- 板上焊 1× 595 + 1× ULN + 一个 2.54 排针接口
- 排针接出 SER/SRCLK/RCLK/OE/SRCLR/VCC/VCCS/GND，**直接接主板的 ESP32**，不另配单片机
- 固件不用改，`set 1 3F` / `hold 1 XX` 现成可用

**流程：** 模块放入 → 压下压板 → 串口全点凸起 → **手摸哪几点没起来** → 记录 → 换下一颗。约 30 秒/颗。

**局限：** 无电学回读，只能手摸。SMA 与线圈通断可用万用表测，但"点起不起得来"是机械问题，电阻正常也可能卡死——正是那 33 个死点的形态。此工装价值是筛选，不是自动测试。

**pogo 选型：** 模块软针且位置有偏差，顶针须选**杯型/皇冠型带凹坑**头，套住针头而非顶在针侧面。

**是否做，取决于无界给出的连接方式。** 若最终弃焊，工装作废。
**现在唯一要做的动作：在 V2 板框旁预留一块拼板区位置**（邮票孔/V 割），画不画到时候再定。多花的成本仅为那点面积。

## 7. 用户访谈对硬件的影响

两次访谈（2026-08-10 n=1；第二位半盲受访者）中**真正落到板子上的只有两条**：

1. **实时反馈需求 → 持续刷新** [必改的热预算]
   即便延迟 1s 可接受，"持续刷新"与"偶尔触发"对电源是两种负载。ULN2803A 与稳压器的散热从**瞬时变连续**，热预算必须重做。VCCS 那颗 Buck 的裕量因此更不能省。**→ 这是 T4（NTC）存在的理由。**

2. **保守告警策略 → 同时凸起点数变少**
   电流均值下降，但**电流裕量仍按最坏情况（全阵列凸起）计算**，不得据此缩小。

**明确否决：板上不做音频通路**（无 codec / 功放 / I2S / 喇叭）。用户已是"一手手机、一手手杖、戴半边耳机"，语音必然从手机出；"偏好本地运行"指不上云，手机端即满足。板上加音频等于重复一套硬件，且与两位受访者一致强调的"简化"相悖。

**本版不做的（无 PCB 影响，转视觉/语音/壳体）：** 负障碍（井盖凹陷）检测、台阶提示、眼镜摄像头、伸缩杖、扁平哑铃握把、语音导航系统。

## 11.5 净变化统计

- **删除：** 14 个位号（1 LDO + 2 电阻 + 3 电容 + 1 磁珠 + 6 排针 + 1 电池座）

- **可测性总增量：** 1 根走线 + 1 排 6 针 + 4 个 0603/热敏 —— 不影响布局
