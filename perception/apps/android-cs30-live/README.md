# CS30 融合点阵 Android 2.0

实时入口复用 CS30 USB 原生深度取流，完成反光复核、几何检障和 K 点阵。RGB-D 回放入口在手机 CPU 上运行 YOLOv8s-seg 和深度融合。应用包名为 `com.lingtouch.cs30fusion`，支持 ARM64 和 x86_64，最低 API 29。
