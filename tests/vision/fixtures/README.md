# 最小回归夹具

`cs30-regression.zip` 约 474 KiB，解包后为 4 帧 640×480 深度、763 字节标定和 K=1–16 的期望点阵。仅供自动测试，生产 APK 不包含这些数据。

这四帧由已有 CS30 的 RGB 对齐导出深度，经当时的近似内参/外参假设投到原生格式。它们是**模拟原生格式**，不能称作真实原生传感器帧，也不是障碍检测真值。夹具用于检查收包/处理/计数/JSON 的软件一致性。

构建工具解包到 `.build/vision/test-assets` 并核对压缩包内的 SHA-256。完整 PNG、源 RAW 和大数据集不作为回归数据新增。可选 RGB-D 原型的 SegFormer 权重另放在根目录 `models`，不属于测试夹具，也不进入生产 APK。
